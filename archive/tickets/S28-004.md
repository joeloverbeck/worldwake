# S28-004: Instrument combat candidates

**Status**: COMPLETED

**Effort**: Medium
**Engine Changes**: Yes — combat emitters populate `KnowledgePath`
**Deps**: S28-001, S28-002

## Problem

Combat candidates (engage hostile, reduce danger, care, loot, bury) need knowledge path instrumentation. All five combat emitters currently use `emit_candidate()` (none use `emit_candidate_with_trace()`). Entity beliefs for hostile targets, wounded entities, and corpses must be traced through provenance. Self-knowledge for own wounds (danger reduction and self-care) must be recorded.

## Assumption Reassessment (2026-03-25, corrected)

1. `emit_engage_hostile_goals` at `candidate_generation.rs:658` — uses `emit_candidate()`. Iterates `local_hostility_targets()` (which calls `hostile_targets_of()`) to get entity IDs without provenance. Cross-reference via `known_entity_beliefs()` needed.
2. `emit_reduce_danger_goal` at line 911 — emits a single goal when agent's danger pressure exceeds threshold. Self-knowledge `OwnWounds { count }` needed.
3. `emit_care_goals` at line 959 — has TWO paths: (a) self-care at line 961 via `has_wounds(agent)` needs `SelfKnowledgeProvenance::OwnWounds`, (b) third-party care at line 976 iterates `known_entity_beliefs()` for wounded others needs `BeliefProvenance` with `Wounded` aspect. Both use `emit_candidate()`.
4. `emit_loot_goals` at line 1240 — iterates `corpse_entities_at()`. Uses `emit_candidate()`. Cross-reference via `known_entity_beliefs()` for `Dead` aspect.
5. `emit_bury_goals` at line 1272 — iterates `corpse_entities_at()`. Uses `emit_candidate()`. Cross-reference for `Dead` aspect.
6. The `emit_combat_candidates` dispatcher at line 240 does NOT currently pass `diagnostics` to any combat emitter. All five sub-emitters must gain a `diagnostics` parameter to use `emit_candidate_with_trace()`.
7. This is an AI diagnostic ticket at the candidate generation layer.

## Architecture Check

1. Combat emitters follow the same pattern as need emitters: cross-reference entity IDs against `known_entity_beliefs()` to extract `PerceptionSource` and `observed_tick`. The pattern established in S28-002 applies directly.
2. No backward-compatibility shims. Upgrading `emit_candidate()` calls to `emit_candidate_with_trace()` is additive.
