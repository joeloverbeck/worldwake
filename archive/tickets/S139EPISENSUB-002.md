# S139EPISENSUB-002: Extend EpistemicDispositionProfile with witness_recency_preference

**Status**: COMPLETED
**Priority**: HIGH
**Effort**: Small
**Engine Changes**: Yes — `worldwake-core` (`epistemic.rs`, `world.rs` test fixture, `save_load.rs` version bump)
**Deps**: archive/specs/S139-epistemic-sensing-subgoals.md

## Problem

S139's emitter (ticket 004) and ranking (ticket 005) need a per-agent freshness-vs-distance weighting parameter (`witness_recency_preference`) that does not currently exist on any profile component. The reassessment confirmed that adding a parallel `EpistemicProfile` component would create dual-truth (FND-28) and semantic overlap (spec-drafting-rules 5f) with the existing universal `EpistemicDispositionProfile`. This ticket extends the existing component with one new field, regenerates the auto-generated profile doc, and bumps the save-format version because the serialized layout of a universal component changes.

## Architecture Check

1. Extending an existing universal component preserves single-source-of-truth for epistemic disposition (FND-28). Adding a sibling `EpistemicProfile` component would create dual truth — every agent would carry two epistemic-disposition profiles whose semantics overlap. The reassessment caught this; the spec was rewritten accordingly.
2. The `#[serde(default)]` annotation on the new field is omitted-field tolerance for authored/self-describing serde inputs, not full old-save compatibility. Live authority always reads the extended struct directly, and old save files remain rejected by `SAVE_FORMAT_VERSION`.

## What Changed

### 1. Add `witness_recency_preference` field to `EpistemicDispositionProfile`

In `crates/worldwake-core/src/epistemic.rs:23-43`:

```rust
pub struct EpistemicDispositionProfile {
    pub stale_evidence_barrier_threshold: Permille,
    pub witness_query_duration_ticks: NonZeroU32,
    pub ask_memory_retention_ticks: u32,
    #[serde(default = "default_witness_recency_preference")]
    pub witness_recency_preference: Permille,
}

fn default_witness_recency_preference() -> Permille {
    Permille::new_unchecked(500)
}

impl Default for EpistemicDispositionProfile {
    fn default() -> Self {
        Self {
            stale_evidence_barrier_threshold: Permille::new_unchecked(400),
            witness_query_duration_ticks: NonZeroU32::new(2).unwrap(),
            ask_memory_retention_ticks: 12,
            witness_recency_preference: default_witness_recency_preference(),
        }
    }
}
```
