# S28-004: Instrument combat candidates

**Status**: PENDING
**Priority**: MEDIUM
**Effort**: Medium
**Engine Changes**: Yes — combat emitters populate `KnowledgePath`
**Deps**: S28-001, S28-002

## Problem

Combat candidates (engage hostile, reduce danger, care, loot, bury) need knowledge path instrumentation. These emitters already use `emit_candidate()` or `emit_candidate_with_trace()` with varying patterns. Entity beliefs for hostile targets, wounded entities, and corpses must be traced through provenance. Self-knowledge for own wounds (danger reduction) must be recorded.

## Assumption Reassessment (2026-03-25)

1. `emit_engage_hostile_goals` at `candidate_generation.rs:643` — need to verify whether it uses `emit_candidate()` or `emit_candidate_with_trace()`. It iterates `visible_hostiles_for()` which returns entity IDs without provenance. Cross-reference via `known_entity_beliefs()` needed.
2. `emit_reduce_danger_goal` at line 838 — emits a single goal when agent has wounds. Self-knowledge `OwnWounds { count }` needed.
3. `emit_care_goals` at line 886 — iterates wounded entities at same place. Uses `emit_candidate()`. Cross-reference via `known_entity_beliefs()` for `Wounded` aspect.
4. `emit_loot_goals` at line 1123 — iterates corpses. Uses `emit_candidate()`. Cross-reference via `known_entity_beliefs()` for `Dead` aspect.
5. `emit_bury_goals` at line 1155 — iterates corpses. Uses `emit_candidate()`. Cross-reference for `Dead` aspect.
6. All combat emitters currently pass `diagnostics` but some use `emit_candidate()` directly. Those using `emit_candidate()` must be upgraded to `emit_candidate_with_trace()` to attach knowledge paths.
7. This is an AI diagnostic ticket at the candidate generation layer.

## Architecture Check

1. Combat emitters follow the same pattern as need emitters: cross-reference entity IDs against `known_entity_beliefs()` to extract `PerceptionSource` and `observed_tick`. The pattern established in S28-002 applies directly.
2. No backward-compatibility shims. Upgrading `emit_candidate()` calls to `emit_candidate_with_trace()` is additive.
