# S27-002: Add InvestigateMissing GoalKind variant and planner support

**Status**: PENDING
**Priority**: HIGH
**Effort**: Medium
**Engine Changes**: Yes — new GoalKind variant, GoalKindTag, PlannerOpKind, goal policy, ranking, feasibility dispatch
**Deps**: S27-001 (needs `ViolationDispositionProfile` for ranking motive extraction)

## Problem

No `GoalKind` variant exists to represent "investigate why an expected entity is missing at a location." Without this variant and its planner/ranking/policy integration, the AI pipeline cannot select, plan, or execute investigation goals even after violation detection emits candidates.

## Assumption Reassessment (2026-03-25)

1. `GoalKind` in `crates/worldwake-core/src/goal.rs` currently has 17 variants. `GoalKey` extraction uses a match arm per variant. Adding variant 18 (`InvestigateMissing { place: EntityId }`) follows the established pattern. Confirmed by file read.
2. `GoalKindTag` in `crates/worldwake-ai/src/goal_model.rs` mirrors `GoalKind` with 17 variants. `GoalKindPlannerExt` trait has methods: `goal_kind_tag()`, `relevant_op_kinds()`, `relevant_observed_commodities()`, `is_satisfied()`, `goal_relevant_places()`, `prerequisite_places()`, `build_payload_override()`, `apply_planner_step()`, `is_progress_barrier()`, `matches_binding()`. Each must be implemented for the new variant. Confirmed by file read.
3. `PlannerOpKind` in `crates/worldwake-ai/src/planner_ops.rs` has op-kind constants and `build_semantics_table()`. The new `Investigate` op needs semantics: `may_appear_mid_plan: false`, `is_materialization_barrier: false`, `transition_kind: GoalModelFallback`. Confirmed by file read.
4. `goal_family_policy()` in `crates/worldwake-ai/src/goal_policy.rs` dispatches on `GoalKindTag`. Confirmed pattern.
5. `rank_candidates()` in `crates/worldwake-ai/src/ranking.rs` uses `ranked_priority_class()` and `ranked_motive_score()` which dispatch on `GoalKindTag`. Confirmed pattern.
6. `feasibility_hint()` in `crates/worldwake-ai/src/feasibility.rs` dispatches on `GoalKindTag` via `goal_specific_feasibility()`. Confirmed pattern.
7. This is a planner-driven ticket. The live `GoalKind` under test is `InvestigateMissing`. The operator surface is `PlannerOpKind::Investigate` with terminal check at investigation place. Affordance surface requires the `investigate` action def (S27-004) but this ticket only wires the planner — affordance/action registration is out of scope.

## What to Change

### 1. Add `GoalKind::InvestigateMissing { place: EntityId }` in `crates/worldwake-core/src/goal.rs`

New variant. Update `GoalKey` extraction match arm: `GoalKind::InvestigateMissing { place } => GoalKey { kind: GoalKind::InvestigateMissing { place }, commodity: None, entity: None, place: Some(place) }`.

### 2. Add `GoalKindTag::InvestigateMissing` in `crates/worldwake-ai/src/goal_model.rs`

New variant. Implement all `GoalKindPlannerExt` methods:
- `goal_kind_tag()`: return `GoalKindTag::InvestigateMissing`
- `relevant_op_kinds()`: return `&GOALS_INVESTIGATE` (new constant: `&[PlannerOpKind::Investigate]`)
- `relevant_observed_commodities()`: return empty (no commodity involved)
- `is_satisfied()`: satisfied when investigate action can start at the place (terminal)
- `goal_relevant_places()`: return `[place]`
- `prerequisite_places()`: return `[place]` (agent must be at investigation place)
- `build_payload_override()`: return `None` (no special payload)
- `apply_planner_step()`: handle `Investigate` op — marks goal progressed
- `is_progress_barrier()`: travel to investigation place is a progress barrier
- `matches_binding()`: terminal check — affordance must target the investigation place

### 3. Add `PlannerOpKind::Investigate` in `crates/worldwake-ai/src/planner_ops.rs`

New variant. Add `GOALS_INVESTIGATE` constant. Add semantics in `build_semantics_table()`: `may_appear_mid_plan: false`, `is_materialization_barrier: false`, `transition_kind: GoalModelFallback`.

### 4. Add goal policy in `crates/worldwake-ai/src/goal_policy.rs`

`GoalKindTag::InvestigateMissing => GoalFamilyPolicy { suppression: WhenStressedAtOrAbove(GoalPriorityClass::High), penalty_interrupt: Never, free_interrupt: FreeInterruptRole::Normal }`.

### 5. Add ranking in `crates/worldwake-ai/src/ranking.rs`

`GoalKindTag::InvestigateMissing`:
- Priority class: `GoalPriorityClass::Low`
- Motive: base from `ViolationDispositionProfile.investigation_motive_weight.as_u32()`, ownership bonus from `ownership_motive_bonus.as_u32()` if agent owns the missing entity (evidence entity lookup).

### 6. Add feasibility dispatch in `crates/worldwake-ai/src/feasibility.rs`

`GoalKindTag::InvestigateMissing`:
- `Likely` if agent's effective_place matches investigation place
- `Uncertain` if agent is not at investigation place
- `Unlikely` if `BlockedIntentMemory` has unexpired entry for the GoalKey
