# S129PLADIRFAC-008: Maintenance — place dirtiness decay and basin natural refill

**Status**: PENDING
**Priority**: MEDIUM
**Effort**: Small
**Engine Changes**: Yes — extends `item_decay_system` maintenance pass with two new per-tick mutations
**Deps**: archive/tickets/S129PLADIRFAC-001.md

## Problem

Without per-tick decay, `PlaceDirtiness.value` only ever increases — places can never recover from accumulated wilderness relief, breaking FND-11's positive-feedback dampener mandate. Without basin natural refill, `WashBasinState.clean_water_units` is consumed once and never regenerates, so the supply chain (well → basin → wash) collapses after a few uses. This ticket adds both maintenance behaviors as new steps inside the existing `item_decay_system` pass — they share the per-tick maintenance window and avoid introducing a new SystemFn (per spec's "SystemFn Integration" note).

## What to Change

### 1. Add `place_dirtiness_decay` step in `item_decay.rs`

Insert a new collection function and apply function modeled on the existing `collect_decay_targets` + `apply_decay` pair. Pseudocode:

```rust
fn collect_place_dirtiness_decay(world: &World) -> Vec<(EntityId, PlaceDirtiness)> {
    world.query_place_dirtiness()
        .filter_map(|(entity, dirt)| {
            if dirt.value == Permille::ZERO { return None; }
            let mut next = *dirt;
            next.value = next.value.saturating_sub(next.decay_per_tick);
            Some((entity, next))
        })
        .collect()
}

fn apply_place_dirtiness_decay(txn: &mut WorldTxn, updates: Vec<(EntityId, PlaceDirtiness)>) -> Result<(), SystemError> {
    for (entity, next) in updates {
        txn.set_component_place_dirtiness(entity, next)?;
    }
    Ok(())
}
```

Wire both into `item_decay_system`'s body alongside the existing decay/pruning calls.

### 2. Add `wash_basin_refill` step in `item_decay.rs`

```rust
fn collect_wash_basin_refills(world: &World) -> Vec<(EntityId, WashBasinState, EntityId, ResourceSource)> {
    world.query_wash_basin_state()
        .filter_map(|(basin, state)| {
            if state.clean_water_units >= state.max_clean_water { return None; }
            let place = world.effective_place(basin)?;
            // Find a Water ResourceSource co-located at the basin's place
            let (source_entity, source) = world.entities_with_resource_source()
                .filter_map(|src| {
                    let s = world.get_component_resource_source(src)?;
                    if s.commodity != CommodityKind::Water { return None; }
                    if world.effective_place(src) != Some(place) { return None; }
                    if s.available_quantity == Quantity::ZERO { return None; }
                    Some((src, *s))
                })
                .next()?;
            Some((basin, *state, source_entity, source))
        })
        .collect()
}

fn apply_wash_basin_refills(txn: &mut WorldTxn, updates: Vec<...>) -> Result<(), SystemError> {
    for (basin, mut basin_state, source, mut source_state) in updates {
        let need = basin_state.max_clean_water - basin_state.clean_water_units;
        let transfer = u16::min(basin_state.refill_per_tick, u16::min(need, source_state.available_quantity.0 as u16));
        if transfer == 0 { continue; }
        basin_state.clean_water_units += transfer;
        source_state.available_quantity = Quantity(source_state.available_quantity.0 - transfer as <whatever Quantity's inner type is>);
        txn.set_component_wash_basin_state(basin, basin_state)?;
        txn.set_component_resource_source(source, source_state)?;
    }
    Ok(())
}
```
