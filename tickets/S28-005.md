# S28-005: Upgrade social and political candidates to traced emission + knowledge paths

**Status**: PENDING
**Priority**: MEDIUM
**Effort**: Medium
**Engine Changes**: Yes — social/political emitters upgraded from `emit_candidate()` to `emit_candidate_with_trace()`, institutional belief provenance populated
**Deps**: S28-001, S28-002, S28-003 (for `institutional_belief_claims()`)

## Problem

Social candidates (`ShareBelief`) and political candidates (`ClaimOffice`, `SupportCandidateForOffice`) currently use `emit_candidate()` which does NOT produce `CandidateEvidenceTrace` entries. They must be upgraded to `emit_candidate_with_trace()` to (a) produce evidence traces and (b) attach knowledge paths. Political candidates additionally require institutional belief provenance via the `institutional_belief_claims()` method added in S28-003.

2. The upgrade makes social/political candidates produce `CandidateEvidenceTrace` records in `diagnostics.evidence` for the first time. This is strictly additive — no existing code reads social/political evidence traces.
3. No backward-compatibility shims.

## What to Change

### 1. Upgrade `emit_social_candidates` to use `emit_candidate_with_trace()`

- Construct `EvidenceTrace` with `CandidateEvidenceContributor` entries:
  - `{ kind: Listener, place, entity: listener }`
  - `{ kind: TellSubject, place, entity: subject }`
- When `ctx.tracing_enabled`: extract `BeliefProvenance` for the subject entity from the `known_beliefs` vec already iterated (line 261). The `BelievedEntityState` carries `source` and `observed_tick`.
- Replace `emit_candidate()` call at line 284 with `emit_candidate_with_trace()`

### 2. Upgrade `emit_claim_office_candidate` to use `emit_candidate_with_trace()`

- Construct `EvidenceTrace` with:
  - `{ kind: OfficeParticipant, place: office_data.jurisdiction, entity: office }`
  - `{ kind: OfficeParticipant, place: office_data.jurisdiction, entity: ctx.agent }` (self as claimant)
- When `ctx.tracing_enabled`: call `ctx.view.institutional_belief_claims(ctx.agent, InstitutionalBeliefKey::OfficeHolderOf { office })` to extract `InstitutionalBeliefProvenance` records
- Replace `emit_candidate()` call at line 526 with `emit_candidate_with_trace()`

### 3. Upgrade `emit_support_candidate_goals` to use `emit_candidate_with_trace()`

- Construct `EvidenceTrace` with:
  - `{ kind: OfficeParticipant, place: office_data.jurisdiction, entity: office }`
  - `{ kind: OfficeParticipant, place: office_data.jurisdiction, entity: candidate }`
- When `ctx.tracing_enabled`: call `institutional_belief_claims()` for `SupportFor { supporter: ctx.agent, office }` to extract provenance
- Replace `emit_candidate()` call at line 593 with `emit_candidate_with_trace()`

### 4. Thread `GenerationContext` reference where needed

The political sub-emitters already receive `ctx` as a parameter, so `ctx.tracing_enabled` is available. No additional parameter threading needed.
