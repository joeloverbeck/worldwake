# .claude/handoffs/

Per-user handoff packets generated by the `/handoff` skill.

- `latest.md` — most recent packet (overwritten each run).
- `YYYY-MM-DDTHHMMSSZ-<slug>.md` — timestamped history.

Contents are gitignored by default; this README and `.gitignore` are checked in so the directory exists.

See `.claude/skills/handoff/SKILL.md` for the skill.
